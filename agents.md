# Water System

## Simplicidade e organização

- Priorizar código direto, responsabilidades claras e poucos arquivos para cada fluxo.
- Nos casos de uso, separar blocos lógicos com linhas em branco, distinguindo consultas, validações, persistência, chamadas externas e retorno. Manter instruções relacionadas juntas e evitar sequências extensas de código sem espaçamento, para facilitar a leitura.
- Usar a estrutura existente quando ela atender à necessidade. Criar pastas ou camadas somente quando houver uma responsabilidade concreta que as justifique.
- Não coloque comentários no código
- Ao desenvolver novos endpoints, lembre-se de padronizá-los para se comunicarem com o 
swagger.
